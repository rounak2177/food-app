# 🍔 Food Ordering Web App

A modern and interactive **Food Ordering Web Application** that allows users to browse different food categories, explore items with images, and select meals easily through a clean and user-friendly interface.


## 🚀 Features

* 🥗 Multiple food categories:

  * Mughlai
  * Thali
  * Pizzas
  * Burgers
  * Momos
  * Salads
  * Rolls
  * Sandwiches
  * Desserts

* 📂 Dropdown menu for each category

* 🖼️ Images for every food item

* 🎯 Clean and intuitive UI

* ⚡ Smooth user experience

* 📱 Responsive design (basic)

## ⚙️ Installation & Setup

1. Clone the repository:

```bash

```

2. Navigate to the project folder:

```bash
cd food-app
```

3. Open the project:

* Open `index.html` in your browser

## 💡 How It Works

* Users select a **food category**
* A **dropdown menu** appears with multiple items
* Each item includes:

  * Name
  * Image
* Users can browse and choose food items easily
